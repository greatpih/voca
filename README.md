# voca

완전 초보도 바로 실행할 수 있게, **딱 1개 파일(`index.html`)** 로 만든 시나모롤 단어 게임입니다.

## 가장 쉬운 실행 방법 (아이패드만 있을 때)
1. 이 저장소에서 `index.html` 파일만 다운로드합니다.  
   (ZIP에 `README.md`만 보이면, GitHub 웹에서 `index.html` 파일을 직접 열어 **Raw 다운로드** 하세요.)
2. 아이패드 `파일` 앱에 `index.html`을 저장합니다.
3. `파일` 앱에서 `index.html`을 한 번 탭해서 엽니다.
4. 게임이 열리면 `게임 시작` 버튼을 누르면 됩니다.

---

## 진짜 초보용: 상황별 실행 가이드

### A) GitHub에서 바로 받아서 실행 (컴퓨터 있음)
1. GitHub 페이지에서 `Code` 버튼 클릭
2. `Download ZIP` 클릭
3. ZIP 압축 해제
4. 폴더 안 `index.html` 더블클릭
5. 브라우저에서 게임 실행

### B) 아이패드만 있을 때 (컴퓨터 없음)
1. GitHub 앱/사파리에서 `index.html` 파일 열기
2. 공유 버튼(⬆️) → `파일에 저장`
3. `파일` 앱에서 저장한 `index.html` 탭
4. 실행 완료

### C) 홈 화면 앱처럼 쓰기
1. 사파리에서 실행한 뒤 공유 버튼(⬆️) 탭
2. `홈 화면에 추가` 선택
3. 이름 입력 후 `추가`
4. 다음부터 아이콘 눌러 바로 실행

---

## 게임 사용법
1. 홈에서 `게임 시작` 누르기
2. 뜻을 보고 영어 단어 입력
3. `정답 확인` 누르기
4. 다 풀면 점수 확인
5. 퍼펙트면 스티커 획득
6. `틀린 문제 복습`으로 오답만 다시 풀기

---

## 단어 바꾸는 방법
1. 홈에서 `단어 수정` 누르기
2. 한 줄에 하나씩 아래 형식으로 입력

```text
apple | 사과
cat | 고양이
```

3. `저장` 누르면 다음부터 새 단어로 테스트

## 시나모롤 이미지를 내가 가진 원본으로 바꾸는 방법
1. 게임에서 `단어 수정` 화면으로 들어갑니다.
2. `원하는 사진 파일 선택`에서 시나모롤 이미지 파일(png/jpg)을 고릅니다.
3. 바로 화면에 반영되고, 다음 실행 때도 유지됩니다.
4. 원하면 `기본 이미지로 되돌리기` 버튼으로 초기화할 수 있습니다.

---

## 자주 생기는 문제
- **이미지가 안 떠요**
  - 최신 버전 `index.html`인지 먼저 확인하세요.
  - 기본 이미지는 시나모롤 PNG(온라인)이며, 네트워크가 안 되면 자동으로 ☁️ 아이콘으로 바뀝니다.
  - 원본과 똑같은 이미지를 원하면 `단어 수정` 화면에서 직접 업로드해 주세요.
- **저장한 단어가 사라졌어요**
  - 사파리 `개인정보 보호 모드`에서는 저장이 유지되지 않을 수 있습니다.
- **입력이 불편해요**
  - 아이패드를 가로 모드로 돌리면 더 편합니다.

- 단어 기본값 키를 `kid-voca-words-v2`로 올려서, 이전 저장 단어장이 있어도 이번 기본 단어장으로 다시 시작됩니다.

## 어디서 실행해서 확인하면 되나요? (완전 쉬운 버전)
### Codex에서 바로 화면 보기 가능?
- 현재 Codex 채팅 창 안에서 실제 브라우저 화면을 직접 띄워서 클릭/플레이하는 기능은 없습니다.
- 그래서 아래 방법(아이패드 파일 앱 / 컴퓨터 브라우저 / 로컬 서버) 중 하나로 확인해야 합니다.

### 1) 아이패드에서 바로 확인
1. `index.html` 파일을 `파일` 앱에 저장
2. 파일을 탭하면 Safari에서 바로 열림

### 2) 컴퓨터에서 확인
1. 프로젝트 폴더에서 `index.html` 더블클릭
2. 기본 브라우저(Chrome/Safari/Edge)에서 열림

### 3) 링크로 열어보게 하고 싶으면 (선택)
- GitHub Pages를 켜면 URL 링크로 어디서나 확인 가능
- 또는 컴퓨터에서 아래 명령 실행 후 같은 와이파이 기기에서 접속
  - `python3 -m http.server 8000`
  - 브라우저에서 `http://localhost:8000/index.html`
