# voca

완전 초보도 바로 실행할 수 있게, **딱 1개 파일(`index.html`)** 로 만든 시나모롤 단어 게임입니다.

## 가장 쉬운 실행 방법 (아이패드만 있을 때)
1. 이 저장소에서 `index.html` 파일만 다운로드합니다.  
   (ZIP에 `README.md`만 보이면, GitHub 웹에서 `index.html` 파일을 직접 열어 **Raw 다운로드** 하세요.)
2. 아이패드 `파일` 앱에 `index.html`을 저장합니다.
3. `파일` 앱에서 `index.html`을 한 번 탭해서 엽니다.
4. 게임이 열리면 `게임 시작` 버튼을 누르면 됩니다.

---

## 진짜 초보용: 상황별 실행 가이드

### A) GitHub에서 바로 받아서 실행 (컴퓨터 있음)
1. GitHub 페이지에서 `Code` 버튼 클릭
2. `Download ZIP` 클릭
3. ZIP 압축 해제
4. 폴더 안 `index.html` 더블클릭
5. 브라우저에서 게임 실행

### B) 아이패드만 있을 때 (컴퓨터 없음)
1. GitHub 앱/사파리에서 `index.html` 파일 열기
2. 공유 버튼(⬆️) → `파일에 저장`
3. `파일` 앱에서 저장한 `index.html` 탭
4. 실행 완료

### C) 홈 화면 앱처럼 쓰기
1. 사파리에서 실행한 뒤 공유 버튼(⬆️) 탭
2. `홈 화면에 추가` 선택
3. 이름 입력 후 `추가`
4. 다음부터 아이콘 눌러 바로 실행

---

## 게임 사용법
1. 홈에서 `게임 시작` 누르기
2. 뜻을 보고 영어 단어 입력
3. `정답 확인` 누르기
4. 다 풀면 점수 확인
5. 퍼펙트면 스티커 획득
6. `틀린 문제 복습`으로 오답만 다시 풀기

---

## 단어 바꾸는 방법
1. 홈에서 `단어 수정` 누르기
2. 한 줄에 하나씩 아래 형식으로 입력

```text
apple | 사과
cat | 고양이
```

3. `저장` 누르면 다음부터 새 단어로 테스트

## 시나모롤 이미지를 내가 가진 원본으로 바꾸는 방법
1. 게임에서 `단어 수정` 화면으로 들어갑니다.
2. `원하는 사진 파일 선택`에서 시나모롤 이미지 파일(png/jpg)을 고릅니다.
3. 바로 화면에 반영되고, 다음 실행 때도 유지됩니다.
4. 원하면 `기본 이미지로 되돌리기` 버튼으로 초기화할 수 있습니다.

---

## 자주 생기는 문제
- **이미지가 안 떠요**
  - 최신 버전 `index.html`인지 먼저 확인하세요.
  - 기본 이미지는 시나모롤 PNG(온라인)이며, 네트워크가 안 되면 자동으로 ☁️ 아이콘으로 바뀝니다.
  - 원본과 똑같은 이미지를 원하면 `단어 수정` 화면에서 직접 업로드해 주세요.
- **저장한 단어가 사라졌어요**
  - 사파리 `개인정보 보호 모드`에서는 저장이 유지되지 않을 수 있습니다.
- **입력이 불편해요**
  - 아이패드를 가로 모드로 돌리면 더 편합니다.

# 🍪 토리의 쿠키 셈놀이 (`math.html`) — 두 자리 수 덧셈·뺄셈

7세 아이용 **100까지의 두 자리 수 덧셈·뺄셈** 연습 게임입니다. `math.html` 파일 하나만 있으면 되고, 인터넷 없이도 돌아갑니다 (영단어 게임과 같은 방법으로 아이패드 `파일` 앱이나 브라우저에서 열기).

## 이렇게 놀아요
1. 아이가 직접 쿠키를 눌러서 옮기고(덧셈), 보라에게 주면서(뺄셈) 수를 손으로 익혀요.
2. 쿠키는 **10개 묶음(파란 띠를 두른 쿠키 탑)** 과 **낱개(10칸 쟁반)** 로 보여요.
   - 덧셈: 낱개가 10개가 되면 1부터 10까지 세면서 한 묶음으로 쌓여요 → **받아올림**
   - 뺄셈: 낱개가 모자랄 때 묶음을 누르면 띠가 풀리며 낱개 10개로 흩어져요 → **받아내림**
3. 4개 보기 중 정답 고르기(또는 숫자 직접 쓰기) → 초록 O + "13만큼 큰 수" 화살표 + **세로셈 풀이**를 보여 줘요.
4. 6문제를 풀면 CLEAR 화면, 별(1~3개)과 보석을 받아요. 틀린 문제만 다시 풀 수도 있어요.

## 단계
| 단계 | 내용 | 예 |
|---|---|---|
| 1 | 10개씩 묶어 세기 | 묶음 3 · 낱개 5 |
| 2 | 몇십몇 + 몇 | 32 + 5 |
| 3 | 몇십몇 + 몇십몇 | 24 + 13 |
| 4 | 몇십몇 − 몇 | 38 − 5 |
| 5 | 몇십몇 − 몇십몇 | 57 − 23 |
| 6 | 받아올림 있는 덧셈 | 38 + 5, 27 + 46 |
| 7 | 받아내림 있는 뺄셈 | 42 − 7, 63 − 28 |
| 8 | 섞어서 도전 (직접 쓰기) | 섞어서 |

## 설정 (오른쪽 위 톱니바퀴)
- 효과음 켜고 끄기
- 한 번에 푸는 문제 수: 6 / 8 / 10
- 답하는 방법: 보기 고르기 / 직접 쓰기
- 기록(별, 보석, 오늘 푼 문제 수)은 그 기기 브라우저에 저장돼요.

## 효과음·글꼴 다시 만들기 (개발용)
원본 파일은 `tools/` 폴더에 있습니다.

| 파일 | 내용 |
|---|---|
| `tools/sfx/*.mp3` | 효과음 원본 15개 |
| `tools/fonts/Cafe24Ssurround.woff` | 글꼴 원본 (카페24 써라운드) |
| `tools/gen_sfx.py` | 효과음 새로 만들기 |
| `tools/embed_sfx.py` | 효과음을 `math.html` 안에 넣기 |
| `tools/embed_font.py` | 쓰인 글자만 골라 글꼴을 `math.html` 안에 넣기 |

```bash
pip install fonttools brotli          # 글꼴 도구에 필요
python3 tools/embed_sfx.py tools/sfx math.html
python3 tools/embed_font.py tools/fonts/Cafe24Ssurround.woff math.html
```
- 화면 문구를 새로 쓰면 `embed_font.py`를 다시 돌려야 새 글자도 같은 글씨로 보입니다.
- 소리를 바꾸려면 `tools/sfx/`의 MP3를 바꾸거나 `tools/gen_sfx.py`로 다시 만든 뒤 `embed_sfx.py`를 돌리세요.
